Semua Kebutuhan Ujian dalam Satu Aplikasi

📷

Multimodal AI OCR

Ditenagai Groq Vision (llama-3.2-11b), Notia mengenali tulisan tangan binder yang berantakan, papan tulis spidol, hingga slide proyektor dosen.

🏷️

Auto-Kategorisasi Matkul

Tidak perlu memindahkan folder satu per satu. AI mendeteksi topik kuliah dari rumus atau teks dan otomatis memasukkannya ke mata kuliah yang sesuai.

⚡

Pencarian Kilat SQLite

Database lokal relasional dengan indexing multi-kriteria. Cari rumus atau teori spesifik jam 2 pagi sebelum ujian dalam waktu di bawah 1 milidetik.

🔒

100% Local-First Privacy

Foto catatan dan data belajar tersimpan di penyimpanan internal smartphone. Tanpa tracking cookies, tanpa server pihak ketiga yang menyimpan fotomu.

📳

Haptic Tactile Polish

Umpan balik getar taktil responsif saat memotret, menyalin ke clipboard, dan menyelesaikan klasifikasi catatan, memberi pengalaman penggunaan yang solid.

📱

Ukuran Ringan (< 50MB)

Dioptimalkan agar tidak membebani memori HP mahasiswa. Bundling efisien tanpa library berlebih, berjalan mulus di HP Android spesifikasi standar.

Pertanyaan Populer

Frequently Asked Questions

Apakah Notia gratis?

Ya, 100% gratis dan open-source di bawah lisensi MIT. Tidak ada biaya langganan, tidak ada iklan tersembunyi.

Bagaimana cara mendapatkan API Key Groq?

Groq menyediakan API key gratis untuk model multimodal vision. Anda cukup membuat akun di console.groq.com dan menyalin kuncinya ke dalam file .env.

Apakah foto catatan saya diunggah ke server?

Tidak. Notia berarsitektur local-first. Seluruh foto dan metadata tersimpan di SQLite lokal ponsel Anda. Foto hanya dikirimkan ke Groq Vision API saat Anda memproses ekstraksi teks, tanpa disimpan permanen di server luar.
