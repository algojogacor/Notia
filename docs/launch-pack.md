## 4. 💼 LinkedIn Professional / Tech Showcase Post

```text
Sebagai mahasiswa/developer, kita sering melihat masalah sederhana di sekitar kita yang dampaknya sangat besar bagi produktivitas harian. Salah satunya: ribuan foto catatan kuliah di smartphone mahasiswa Indonesia yang tercecer dan berakhir sia-sia.

1. Local-First Relational Engine: Dibangun di atas React Native (Expo SDK 57) dengan expo-sqlite on-device. Latensi kueri tercatat di bawah 0.3ms untuk ratusan catatan.

3. Privacy & Zero Footprint: Tanpa server penyimpanan pihak ketiga, ukuran bundle Android dioptimalkan di bawah 50MB.

Project ini sepenuhnya Open Source di bawah lisensi MIT.
```
